# Requisitos del proyecto

## Requisitos funcionales

La aplicación deberá permitir:

- Registrar un gasto, indicando obligatoriamente la fecha, el importe y la categoría. Opcionalmente el usuario podrá añadir una breve descripción al gasto.
- Modificar la fecha, el importe o la categoría de un gasto.
- Eliminar un gasto registrado.
- Consultar el listado de todos los gastos.
- Buscar gastos.
- Filtrar gastos por categoría.
- Mostrar el importe total de los gastos.


## Requisitos no funcionales

La aplicación deberá cumplir los siguientes requisitos:

- Tener una interfaz sencilla e intuitiva.
- Estar desarrollada en Java.
- Almacenar la información en una base de datos gestionada por PostgreSQL.
- Estar dirigida a un único usuario.
- La interfaz de la aplicación estará en español.

## Funcionalidades futuras

En futuras versiones podrían añadirse las siguientes funcionalidades:

- Estadísticas por categorías.
- Gráficos de gastos.
- Comparativa de gastos entre meses.
- Exportación de datos (PDF o Excel).
- Gestión de varios usuarios.
- Soporte para varios idiomas.
- Permitir modificar de forma independiente cada campo de un gasto.
